# Uiprobe

Uiprobe compares a live webpage against its Figma design and reports every difference in text, fonts, colours, sizes, spacing and layout, with the expected and the actual value for each.

Run it from the [web app](https://app.uiprobe.io), the [Chrome extension](https://chromewebstore.google.com/detail/uiprobe/opcfheiigjnncbbaljoilbaokpmojpjj), the [Figma plugin](https://www.uiprobe.io/figma-plugin), or your coding agent through the Uiprobe MCP server.

## Plugins

- [claude-plugin](https://github.com/uiprobe/claude-plugin): Uiprobe for Claude Code. Probe a page, then let Claude fix the differences in your code.
- [chatgpt-codex-plugin](https://github.com/uiprobe/chatgpt-codex-plugin): Uiprobe for ChatGPT and Codex.
